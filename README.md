# Calculadora Quântica de Configuração Eletrônica

Calculadora visual de configuração eletrônica para elementos de Z = 1 a 118.

## Funcionalidades

- Configuração completa e notação de gás nobre
- Diagrama visual de orbitais (caixas + setas de spin) seguindo a Regra de Hund
- Números quânticos do elétron diferenciador
- Tratamento de anomalias experimentais (Cr, Cu, Mo, Ag, Pd, etc.)
- Interface moderna e responsiva

## Como usar

Abra o arquivo `index.html` em qualquer navegador ou acesse a versão hospedada.

## Deploy

Repositório pronto para deploy no Netlify / Vercel / GitHub Pages.
